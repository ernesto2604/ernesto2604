### 🚀 Featured Engineering Projects

#### ⚡ [Enterprise Hybrid RAG Engine API](https://github.com/ernesto2604/hybrid-rag-api)
- **Core Focus:** Production RAG Systems & Deterministic Information Retrieval.
- **The Solution:** An end-to-end hybrid RAG engine built **from scratch** without black-box frameworks (no LangChain/LlamaIndex). Integrates dense vector search (HNSW cosine) and sparse lexical search (GIN tsvector) inside PostgreSQL.
- **Key Engineering:** Custom **Reciprocal Rank Fusion (RRF)** ranking, concurrent page-level chunking with exponential backoff retries, multi-document JSONB isolation, and verifiable page-level citation attribution.
- **Tech Stack:** Python 3.11+, FastAPI, PostgreSQL 16, pgvector, Gemini Embeddings, Docker.

#### 🔔 [Ring TelemetryOps: Autonomous Diagnostic & Remediation Agent](https://github.com/ernesto2604/ring-telemetryops)
- **Core Focus:** Autonomous Agentic AI & Deterministic Video Telemetry.
- **The Solution:** Real-time diagnostic agent for smart video doorbells (Amazon Ring) detecting and remediating stream degradation (FPS drops, bitrate degradation, lens blur).
- **Key Engineering:** Computer vision telemetry pipeline via OpenCV (Laplacian variance) with early-exit branching for healthy streams. Routes degraded streams and metrics into **Amazon Bedrock (Claude 3 Haiku)**, grounded against technical SOPs for automated remediation reports.
- **Tech Stack:** Python, Amazon Bedrock, Anthropic Claude 3 Haiku, OpenCV, REST.

#### 📍 [WakeMap — Smart Travel & Location Services](https://github.com/ernesto2604/wakeMap_submission)
- **Core Focus:** Full-Stack Mobile & Applied Generative AI.
- **The Solution:** Cross-platform mobile app combining real-time geofenced tracking alarms with dynamic itinerary generation tailored to user time, constraints, and budget.
- **Key Engineering:** Asynchronous backend built with FastAPI, containerized PostgreSQL with JWT auth, and Gemini LLM API integration.
- **Tech Stack:** Flutter, Dart, FastAPI, PostgreSQL, Docker, Gemini API, Google Maps API.

#### 🔐 [Secure Authentication Engine](https://github.com/ernesto2604/secure-auth-go)
- **Core Focus:** Backend Security & Cryptographic Integrity.
- **The Solution:** Hardened web application in Go implementing secure session state, token invalidation, CSRF protection, and rate limiting to prevent automated brute-force vectors.
